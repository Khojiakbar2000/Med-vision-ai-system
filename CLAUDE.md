# Project privacy rules

- Keep original DICOM files and scrubbed copies outside this project and coding workspace.
- Never read, list, glob, search, attach, summarize, or request files from protected medical-data folders.
- Never print filenames, DICOM headers, patient identifiers, UIDs, pixel data, or raw loader errors.
- The browser may process files only after the user explicitly chooses a folder.
- Do not add analytics, telemetry, uploads, remote storage, external image URLs, or network requests.
- Build and test only with application source and synthetic DICOM fixtures.
- This is educational and research software, not for diagnosis.
